| Boundary | Description |
|----------|-------------|
| Streamlit app → Apollo.io | Master API key crosses to an external HTTPS service |
| Streamlit app → public DNS | SENDING_DOMAIN (admin config) interpolated into DNS query names |
| exceptions → user | Raw tracebacks could leak internal detail to a non-technical user |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-02 | Information Disclosure | Uncaught exceptions surfacing Streamlit's traceback view to users | mitigate | All `requests`/`dns.resolver` calls wrapped in try/except returning a plain-language banner tuple; functions never raise (RESEARCH.md line 590, SC-2). |
| T-03-03 | Input Validation (V5) | SENDING_DOMAIN interpolated into DNS query names | mitigate | `_valid_domain()` guard rejects empty/malformed domains before any `resolve()` call, preventing malformed DNS queries from admin-misconfigured config (RESEARCH.md line 582). |
