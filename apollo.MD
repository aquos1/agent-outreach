# Apollo API

Search, enrich, create, and manage Apollo data programmatically.

## Start building

Here's how:

|                        |                                                                                                                                                                                                                                                                      |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Authenticate**       | Apollo users authenticate with an API key. [Get an API key](https://docs.apollo.io/docs/create-api-key).<br><br>Partners building on behalf of mutual customers authenticate with OAuth 2.0. [Set up OAuth](https://docs.apollo.io/docs/use-oauth-20-authorization-flow-to-access-apollo-user-information-partners). |
| **Test your access**   | Call `auth/health` to [test your API key](https://docs.apollo.io/docs/test-api-key) and confirm you're ready.                                                                                                                                                                                |
| **Review limits**      | [Review rate limits](https://docs.apollo.io/reference/rate-limits) and [credit usage](https://docs.apollo.io/docs/api-pricing) to understand endpoint guardrails.                                                                                                                                                         |
| **Handle errors**      | [Review status codes and errors](https://docs.apollo.io/reference/status-codes) to prep for failed requests.                                                                                                                                                                                      |
| **Work in your tools** | [Download the OpenAPI specification](https://docs.apollo.io/reference/openapi-specification) to import endpoints directly into Postman or another API client.                                                                                                                                     |

Now you're ready to dig into the endpoints.
